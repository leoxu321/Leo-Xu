# Leo Xu – Personal Portfolio Website

This repository contains the source code for my personal portfolio website, built with **Vite** and deployed using **GitHub Pages**. The site highlights my background, experience, and projects in **Machine Learning**, **Data Science**, and **Software Engineering**.

🌐 **Live Website:**  
https://leoxu321.github.io/Leo-Xu/

---

## ✨ Overview

This portfolio serves as a central hub to showcase:
- Professional experience and internships
- Machine learning and data science projects
- Technical skills and tools
- Education and contact information

The design emphasizes a **modern, dark-themed, developer-focused aesthetic**, with an emphasis on clarity, performance, and responsiveness.

---

## 🛠 Tech Stack

- **Vite** – Frontend tooling and build system
- **HTML5**
- **CSS3** (custom styling, no UI frameworks)
- **JavaScript (ES Modules)**
- **Google Fonts** (Inter, JetBrains Mono)
- **Devicon** for technology icons
- **GitHub Pages** for hosting
